# ADR 005 — Atmospheric evidence extension

Preserve current hourly forecasts, tides and coastal checks. Add a provider-independent atmospheric port and NWS adapter. Use documented points discovery, raw grid skyCover/windGust intervals and nearby station observations. Only use a discovered observation station within 25 km, disclose its coordinates/distance, and never present it as a shoreline observation. Atmospheric pressure is station pressure (Pa → hPa), not sea-level pressure. Trend is arithmetic hPa/hour between same-station observations separated by 2–4 hours, not a scientific suitability score. Observation freshness: 90 minutes; grid update freshness: 6 hours; provider clock lead: 2 minutes. These are explicit operational policies.

Point astronomicalData, when present, supplies sunrise/sunset/civil twilight with explicit offsets. Validate chronological order and local calendar date. Classify natural light from these calculated events only, not actual illuminance under clouds. Missing data stays unavailable. Each branch fails independently. No alert activation or new scoring.

Sources checked 2026-10-19: https://www.weather.gov/documentation/services-web-api ; https://api.weather.gov/openapi.json ; live SF points/grid data. NWS open data is free for any purpose, User-Agent required, rate limit unpublished, grids approximately 2.5 km, hourly periods vs variable grid intervals distinct; marine coverage may require raw grids. Stations may be delayed by upstream processing. USNO API documentation https://aa.usno.navy.mil/data/api reviewed; live request returned HTTP 503, not selected as a fallback. No guaranteed nationwide or all-coastal parameter coverage claimed. astronomy optional extension requires validation, never assumed present.
